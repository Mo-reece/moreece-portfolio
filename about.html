Who I am

I work across the whole stack, and I like it that way.

I'm Okurut Maurice Leonard, a solutions architect and full-stack engineer in Kampala, Uganda. I take on the whole delivery: architecture, React interfaces, Python and Node services, SQL systems, reporting, machine learning, and automation. Handing a project between four suppliers is where most of the detail gets lost.

At Logos Cloud Services I build pipelines, reporting workflows, and model-ready datasets for SME clients in fintech, agribusiness, and logistics. I also collaborated on Aristoc Booklex, a live e-commerce platform for an established Ugandan bookstore chain, where I worked across the full stack.

Earlier local-government work taught the rest: handling official records carefully, checking integrity before reporting, and explaining findings in plain language.

What guides the work

  • Reliability before presentation. A polished dashboard cannot compensate for incomplete or inconsistent source data.
  • Context before tooling. The reporting question and operating process determine the right technical approach.
  • Clarity for the end user. Documentation and data storytelling are part of the solution, not an afterthought.
  • Maintainability after delivery. Repeatable workflows, checks, and handover notes make the work usable beyond a single analysis.

Working approach

The same four steps, whatever the problem is.

The technology changes constantly. This sequence hasn't needed to.

Understand

Clarify the decision, user, source systems, constraints, and definition of a useful result.

Structure

Map fields, define consistent formats, and establish validation rules before analysis.

Build

Implement the pipeline, database, report, dashboard, or automation in testable steps.

Handover

Document assumptions, checks, and recurring tasks so the solution remains understandable.
