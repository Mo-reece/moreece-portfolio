# Security Policy

## Supported Version

The deployed version from the default branch is supported.

## Reporting a Vulnerability

Please do not open a public issue containing exploit details or personal data.
Report suspected vulnerabilities by email to
[okurutmauriceleonard@gmail.com](mailto:okurutmauriceleonard@gmail.com).

Include the affected URL, reproduction steps, impact, and any suggested mitigation.
You should receive an acknowledgement within 72 hours.
